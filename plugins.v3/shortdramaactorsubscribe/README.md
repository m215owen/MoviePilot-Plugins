# 短剧演员（ShortDramaActorSubscribe）

跟着喜欢的**短剧演员**追剧：把演员名填进来，插件从**短剧百科**（duanjubaike.org）取回他们的
全部作品，铺成一面和宿主「探索」页同形的海报墙；看中哪部点「订阅」，走的就是
**MoviePilot 自己的订阅系统** —— 搜索、下载、整理全部由系统接管。

```
填演员 → 短剧百科取作品 → 作品墙（侧栏「短剧演员」）
                              ↓ 点「订阅」
                       宿主原生订阅对话框 → 系统订阅 → 系统搜索/下载/整理
                       （配置页指定了「订阅下载器」时改为直接提交，并带上下载器偏好）
```

> **一句话定位（2026-10-15 重写）**：本插件**只做发现**。
> 自建的站点搜索 / 择优下载 / 账本去重 / 自建订阅表 / 自建整理入库 / 自写 NFO
> 这一整条链路已**全部删除** —— 短剧百科已作为一等媒体数据源接入宿主框架（能出卡片、
> 能开媒体详情页），宿主的订阅系统认 `media_source` + `media_id` 这种显式身份，
> 因此订阅这件事交还给系统既更短也更可靠。

## 界面（侧栏「短剧演员」）

- 落在宿主侧栏的**订阅分组**里，与「电影订阅 / 电视剧订阅」并列。
- 版式与宿主「探索」页一致：**海报卡片**（2:3，自适应列宽）+ 宿主 MediaCard 同款角标
  （左上「短剧」、右上评分）+ **悬停浮层**（年份 / 剧名 / 简介 + 左搜索右订阅按钮排，
  hover 抬升 4px）。**点卡片进宿主媒体详情页**。
- **向下滚动自动加载下一页**（与探索页同一种加载方式）：首屏 60 部，滚到底再取下一批，
  页尾显示「已到末尾 · 共 N 部」。
- 顶部分类筛选栏**与宿主「探索」页同一套组件**：一行一个维度，
  左侧是维度名（`VLabel`：版权方 / 类型 / 演员 / 年份 / 排序 / 搜索，顺序按用户定的排版），
  右侧是 `VChipGroup` 里的一排 `VChip{filter, tile}` —— 选中项前面的 ✓ 就是 `filter`，
  主色高亮，**再点一次即取消**（没有「全部」按钮，与探索页一致）。
  - **版权方**（真机 60 项）、**类型**（真机 60 项）、**演员**（每人带作品数）选项多，
    **默认只铺一行（12 项）+ 行尾「展开」按钮**，展开后铺全部并可「收起」；
    展开行是**换行排布**（column 模式），没有左右滑动箭头；每项都带作品数，按作品数从多到少排；
  - **排序**是「热度 / 播放 / 评分 / 发布日期」，排的全是作品自带的真实数值
    （日期新剧在前；缺数据的作品排最后）；
  - **搜索**行搜的是**演员**（不是剧名）：输入名字交短剧百科查，结果用同一套卡片显示。
    已关注的演员按钮是**「取消订阅」**（移出关注列表）；**点卡片**展开这位演员的
    作品墙（百科实时取，`/actors/works`，无需先关注）。
- 筛选栏里**没有任何按钮**（探索页同款）：加演员走「搜索」行搜人后点卡片上的「订阅」，
  设置在宿主的插件管理里进。

### 筛选与排序口径

| 维度 | 数据来源 | 说明 |
| --- | --- | --- |
| 类型 | 作品卡的题材标签 | 卡上是**摘要**（只印 1~3 个），详情页才是全量 ⇒ 这一栏按摘要标签筛 |
| 年份 | 作品首播年 | 卡片只给首播日期时取年份部分 |
| 演员 | 本插件的关注名单 | 一部剧多位演员参演时，命中任一即可 |
| 版权方 | 作品数据源 | **目前只有作品详情页才有**；数据源把这一项补进作品条目后，这一栏自动出现（没有数据时整栏隐藏，不拿空标签充数） |
| 排序 · 热度 | 作品自带的热度 | 默认排序，降序；没有该数据的作品排最后 |
| 排序 · 播放 | 作品自带的播放量 | 降序；没有该数据的作品排最后 |
| 排序 · 评分 | 作品自带的评分 | 降序；没有评分的作品排最后 |
| 排序 · 发布日期 | 作品的首播日期 | 降序（新剧在前）；没有日期的作品排最后 |

> 站点的**演员页卡片只印**「热度 / 播放 / 首播 / 标签 / 评分 / 集数」这几项，
> 没有「收藏」这个数据（演员页、详情页、排行榜都没有）—— 所以排序里没有收藏。

筛选、排序、分页都在**后端**做（真机 95 位演员 = 2256 部），前端只负责取当前页。

## 卡片上的三个动作

| 动作 | 行为 |
| --- | --- |
| **搜索**（悬停浮层左下放大镜） | 跳宿主的资源搜索页 `#/resource?area=title&media_source=duanju&media_id=…`，参数口径与宿主 MediaCard 的 `handleSearch` 一致；**配置页勾选了「资源搜索站点」时**额外带 `sites=<id,…>`，只在配置的站点里搜（不勾 = 走系统默认） |
| **订阅**（悬停浮层右下爱心，与系统同款） | 调宿主注入的 `nativeSubscribe`，弹出**系统自带的订阅对话框**（选季、质量、目录等一律由系统负责），建出来的就是系统订阅 |
| **点卡片** | 跳宿主的媒体详情页 `#/media?media_source=duanju&media_id=…&type=电视剧`，由系统按百科身份渲染 |

已订阅的作品，浮层里的爱心会变成红色实心（读宿主 `subscribe/` 列表里 `media_source`
为 `duanjubaike` 的条目）；海报上的角标只有「短剧」类型徽标与评分徽标两枚，与探索页
MediaCard 同款。

> **为什么是 `duanju` 而不是 `duanjubaike`**：`duanju` 是短剧百科作为宿主媒体数据源的
> **规范标识**（`ShortDramaBaikeSource` 对外声明的就是它，宿主来源目录与分类规则的
> `sources` 都按它匹配），`media_id` 则是**裸数字**。官方插件开发文档要求通用链路里的
> 媒体身份必须同时是 `media_source + media_id` —— 用旧标识订阅出去的条目会被当成
> 另一个来源，分类规则里的来源过滤就落空了。旧标识只在百科插件的别名表里**读兼容**。

## 添加演员

界面上只有一条路：**「搜索」行搜人 → 卡片点「订阅」**。插件先到短剧百科里查：

- **完全同名**的候选只有一位 → 直接采纳；
- 有多位候选 / 没有完全同名 → 把候选都列出来让你点一位确认（**绝不自动错配**成另一个演员）；
- 百科没收录 → 显示「没找到」（这是稳定结果，不是故障）。

解析出的百科演员 ID 会写进快照，之后每轮直接按 ID 取作品页，不再走站外索引。

也可以在**宿主插件管理的设置页**里用文本框**批量粘贴**（一行一位或用逗号分隔）。

## 搜索演员

筛选栏「搜索」行搜的是**演员**（不是剧名）：输入名字（防抖 0.4 秒）交给短剧百科，
召回的演员用与作品墙**同一套卡片**渲染 —— 「海报」位放演员头像，悬停浮层显示
作品数 / 身份 / 姓名 / 简介，卡上两个动作：

| 动作 | 行为 |
| --- | --- |
| **百科页** | 新标签打开百科的演员页 |
| **订阅（人形 + 号）** | 把这位演员**加进本插件的演员表**（不是剧集订阅），加了之后作品墙与「演员」筛选行立即带上他；已在列表里的显示绿色对勾 |

头像与作品数来自百科插件的演员档案（`/actor` 接口，卡片先出、头像渐进补上，
补不到就显示人形占位图）。**搜索是查站外索引，慢的时候 40 秒级**，前端已放宽超时；
百科没召回时显示「没找到」空态 —— 换个名字再试即可（百科只收录站上有的演员）。

## 刷新节奏

| 节奏 | 默认 | 说明 |
| --- | --- | --- |
| 作品发现 | 12 小时 | 刷新演员作品快照，新作品发一条汇总通知 |
| 快照刷新 | 24 小时 | 演员页要真抓一次网络，快照按小时级刷新；没到期的演员直接沿用缓存 |
| 失败重试 | 20 分钟 | 解析失败是可自愈的临时故障，按分钟级重试 |

首轮解析可能拉长到几十分钟（每位演员一次站外索引检索），因此**每解析完一位就落一次盘** ——
宿主随时可能重载插件，整轮结束才写盘会把进度全丢。

## 「新作品」的口径

作品**首次出现**晚于该演员的**基线时间**（加入那一刻）、且距今在 **3 天**内 ⇒ 标「新」。

- 基线那一轮的作品**不算新** —— 否则一次导入十几位演员会整片标成新作品；
- 标记**不落盘**，每次查询现算，所以过期的「新」会自己消失。

## 接口（`auth: "bear"`，面板与脚本可共用）

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/status` | 演员数 / 作品数 / 新作品数 / 最近刷新 |
| GET | `/works` | 作品墙，一页一条记录。参数：`actor` / `genre` / `year` / `studio` / `sort`（`heat`\|`play`\|`rating`\|`date`）/ `keyword` / `page` / `page_size`。响应带 `total` / `has_more` / `facets`（类型·年份·版权方及各自作品数） |
| GET | `/actors` | 演员列表（含解析状态、百科 ID、作品数） |
| POST | `/actors/search` | 在百科里查演员。请求体 `{name, enrich}`；`enrich` 为真时给前 12 位候选补档案（头像 / 作品数 / 简介 / 性别 / 国籍，补不到就只有名字） |
| POST | `/actors/add` | 添加演员（`actor_id` 缺省时按同名精确匹配） |
| POST | `/actors/remove` | 移除演员（连同快照） |
| POST | `/refresh` | 立即刷新全部演员 |
| GET / PUT | `/config` | 读写配置 |

## 配置

| 项 | 默认 | 说明 |
| --- | --- | --- |
| `actors` | 空 | 关注的演员，一行一位或逗号分隔 |
| `interval_hours` | 12 | 作品发现间隔（也是演员快照的保鲜期：每轮重抓距上次已超过一个间隔的演员） |
| `retry_minutes` | 20 | 解析失败重试间隔 |
| `notify` | 开 | 新作品发系统通知 |
| `sidebar_nav` | 开 | 侧栏显示「短剧演员」入口 |
| `search_sites` | 空 | 资源搜索站点：逗号分隔的站点 ID（空 = 不限定，走系统默认） |
| `subscribe_downloader` | 空 | 订阅下载器：宿主下载客户端的名字。配置后作品墙点「订阅」按此下载器直接提交（不弹系统订阅对话框）；空 = 弹对话框、跟随系统默认 |

## 依赖

- **短剧百科数据源插件**（`ShortDramaBaikeSource`）必须已安装并启用 —— 作品全部来自它，
  经 `self.chain.run_module("search_actors" / "actor_works")` 跨插件取数，不走 HTTP 自调用。
- 没装 / 停用时，演员会显示为「等待自动重试」，作品墙为空，不影响其它功能。

## 已知边界

- 作品卡上的**题材标签是摘要**（1~3 个）、**没有版权方**，这两项的全量数据只有作品详情页有；
  版权方这一栏等数据源把它带进作品条目后自动可用（现在没有数据时整栏隐藏）。
- 站点**没有「收藏」数据**，所以排序只有热度与播放。
- 百科未收录的演员会稳定显示 `empty`（不是故障，不会反复重试）。
- 作品的媒体身份是百科自己的 ID（`duanjubaike` + `duanju:45982` / 旧前缀 `org:34146`），
  宿主建订阅时若配置 `RECOGNIZE_SOURCE=themoviedb`，日志会留一条「未能转换为 TMDB 身份，
  订阅沿用原身份」—— 这是正常的，订阅照样生效。
- 作品字段版本升级（例如作品条目新增筛选字段）后，旧快照会在下一轮刷新时自动重抓一次；
  重抓按剧名继承原有的「首次出现时间」，不会把整墙作品误判成新作品。
