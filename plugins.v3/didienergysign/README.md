# 滴滴能源签到（DidiEnergySign）

每日自动完成滴滴能源（小桔充电）微信小程序的签到打卡，本地记录累计/连续天数，连续满 5 天平台发放优惠券；凭证失效或结果异常时通过 MoviePilot 通知渠道提醒。

## 功能

- 按 cron 周期自动签到（默认每天 08:10），当日已签自动跳过，不重复请求
- **先查签到页状态再动手**：每次执行先拉小程序签到页的数据源接口
  `POST /am/marketing/api/member/charge/activity/sign/main`，页面日历显示今天已签则直接确认收工，确认未签才调 `doSign`
- 本地持久化签到记录（累计 / 连续 / 最大连续 / 最近 30 天历史），存宿主插件数据区，重装插件不丢
- 签到结果判定区分五种状态：**成功 / 已签（页面确认）/ 未确认（可能已签）/ 失败 / 异常**
- 失败自动重试：业务失败按 5 秒 → 10 秒递增间隔最多重试 2 次（共 3 次尝试）；请求层异常与「未确认」结果不盲重试
- 可选通知：失败必发，成功是否发由「成功也通知」开关控制
- 对外 API：`POST /api/v1/plugin/DidiEnergySign/run`（手动/自动化触发，可 `force=true` 强制请求）、`GET /api/v1/plugin/DidiEnergySign/status`（读本地记录）

## 配置

| 配置项 | 说明 | 默认 |
| --- | --- | --- |
| 启用插件 | 关闭后不再定时执行 | 关 |
| 签到凭证 ticket | 微信小程序「滴滴能源」抓包获取（请求头/请求体里的 `ticket` 字段），站点下发、可能过期 | 必填 |
| 城市 ID | 签到接口 `cityId` | 5 |
| 活动 ID | 签到接口 `excitationId` | 144115195993789098 |
| 执行周期 | 5 位 cron | `10 8 * * *` |
| 发送通知 | 失败/未确认时推送 | 关 |
| 成功也通知 | 成功时也推送一份 | 关 |
| 请求超时 | 秒 | 10 |
| 代理地址 | 留空直连 | 空 |

多账号：一个凭证一个实例，用宿主「虚拟分身」给本插件建多个分身分别配置即可（配置与数据按实例隔离）。

## 关于「未确认」结果（重要）

**2026-10-22 实测**：当日已签时，`doSign` 并不返回"已签到"文案，而是与普通失败相同的 `DO_SIGN_ERROR`/「签到失败，请稍后重试」。因此插件以**签到页数据源**（`sign/main`，与小程序签到页渲染同源）为权威判定：

- 执行前先查页：页面 `signRecordDTOList` 含今天 → 直接按已签处理、写记录，不调 `doSign`；
- `doSign` 返回模糊错误时回查页面仲裁：页面确认今天已签 → 按重复成功处理并写记录；
- 只有「页面不可用 + doSign 模糊错误」才标记**未确认**：不写入签到记录，下次执行再试，通知里会说明。

这保证了签到记录只会在站点侧真实已签时更新，不会把没签上的日子标成已签。

## 凭证失效的表现与处理

ticket 由站点下发、有效期由站点控制。失效时签到持续返回失败/未确认，且小程序里能确认当天并未签上 → 重新抓包获取新 ticket 填入配置即可。
