# 订阅批量编辑器（SubscribeBatchEditor）

MoviePilot **V3** 插件。按规则筛选订阅，批量修改其**订阅站点、下载器、保存路径、
包含 / 排除规则、洗版状态、订阅状态与订阅归属用户**。

## 为什么需要它

MoviePilot 的订阅只能在详情页逐条修改。当订阅数量较多时——尤其是**插件自动创建**的
一批订阅——逐条改写的成本极高。本插件把「筛选 + 批量改写」做成一次可重复执行的动作，
并支持在新增订阅时自动触发。

## 核心特性

### 1. 支持筛选「插件发起的订阅」（本插件的差异点）

MoviePilot 中由插件创建的订阅，会把 `username` 直接写成**插件名**。本机实例实测：

| username | 条数 | 性质 |
| --- | --- | --- |
| `m216owen` | 13 | 真实用户手动订阅 |
| `豆瓣演员订阅` | 6 | 插件发起（DoubanActorSubscribe） |
| `embykit` | 2 | 插件发起（EmbyKit） |
| `订阅助手（增强版）` | 1 | 插件发起 |

这些取值**不在系统用户表里**，因此宿主的「订阅用户」筛选与常规插件都选不到它们。

本插件在生成配置页时**动态扫描订阅库**，把三类取值合并成一个可多选的
「订阅来源 / 用户」列表：

- 系统用户（来自 `UserOper.list()`）
- **插件来源**（订阅库中出现、但不在用户表里的 username），界面标注为 `（插件 · N 条）`
- **（无归属用户）**：`username` 为空的订阅

因此可以精确筛选并批量改写插件自动创建的订阅。

### 2. V3 契约合规

- 宿主依赖全部走 `app.sdk.*` 稳定入口，不引用 `app.core` / `app.db` / `app.helper`。
  数据访问使用 `app.sdk._legacy.subscribe` / `site` / `user`（宿主为兼容旧插件保留、
  已收拢进 SDK 命名空间的官方入口）。
- 渲染模式沿用宿主默认的 `vuetify`：配置页与详情页由后端下发 Vuetify 组件 JSON，
  **无需自带前端产物**，也不依赖模块联邦。
- 一次性任务交由宿主调度器托管（`app.sdk.scheduler`），不再自建 `BackgroundScheduler`。

## 筛选规则

| 规则 | 说明 |
| --- | --- |
| 媒体类型 | 不限 / 电视剧 / 电影。**默认仅电视剧**，与 1.x 行为保持一致 |
| 订阅来源 / 用户 | **多选**。可选系统用户、插件来源、（无归属用户）；不选表示不限 |
| 集数小于 / 大于 | 按订阅的 `total_episode` 过滤，任一满足即命中，留空不限 |
| 洗版状态 | 不限 / 关闭 / 开启 |

## 修改策略

留空的项**不会被修改**（只提交显式设置的字段）。

| 策略 | 说明 |
| --- | --- |
| 新站点 | 替换订阅的搜索站点（多选，来自系统站点列表） |
| 新下载器 | 替换订阅的下载器（下拉，来自系统已配置下载器） |
| 新保存路径 | 替换订阅的保存路径 |
| 新洗版状态 | 关闭 / 开启 |
| 新订阅状态 | 订阅中 (R) / 待定 (P) / 暂停 (S) |
| 新订阅归属用户 | 把匹配到的订阅改归到该用户名下 |
| 包含 / 排除规则 | 替换订阅的正则包含 / 排除规则 |

## 运行方式

1. **配置页「立即运行一次」**：保存配置时勾选，由宿主调度器延迟 3 秒执行一次。
2. **远程命令**：`/batch_edit_subscribes`。
3. **新增订阅事件**：启用后，新增订阅（媒体类型与筛选一致时）会自动触发一次批量改写。

> 若修改策略为空，`batch_edit` 会直接跳过，不会产生副作用。

## HTTP 接口

挂载在 `/api/v1/plugin/SubscribeBatchEditor/`。

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/preview` | 预览命中筛选条件的订阅（不修改数据） |
| GET | `/sources` | 列出可用的订阅来源（用户 / 插件 / 无归属） |
| POST | `/apply` | 应用修改策略，返回成功 / 失败统计 |

## 安全说明

- 批量改写**不可撤销**。建议先通过插件详情页或 `/preview` 确认命中数量与条目。
- 写入前会读取每条订阅的原值并记录到日志（`改前 -> 改后`）。
- 修改「订阅归属用户」可能影响发起该订阅的插件对它的管理逻辑（例如插件按自己的
  username 反查订阅），请谨慎使用。
